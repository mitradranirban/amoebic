Amoebic color variable font

Amoebic is part of Tiny Fun Font series. These are limited character set font for having fun with color and/or variable font technology, created using free open source tools.

Here each character can degenrate into an identical amœba at SHAPE axis value of zero, OR takes shape of a full fledged letter form on reaching SHAPE axis value of 100.
